# LYRICAL-GRAPHQL

## About The Project

A GraphQL practice application with a React client and an Express GraphQL server, using MongoDB. Starter project from a GraphQL course on Udemy.com, per the original README.

### Built With

- React
- GraphQL (Express server)
- MongoDB (Docker Compose)
- Webpack

## Getting Started

### Prerequisites

- Node.js and npm
- Docker and Docker Compose (for MongoDB)

### Setup

- Run `npm install --legacy-peer-deps` in the root of the project to install dependencies
- Start MongoDB with `npm run mongo:start`
- Access the application at `localhost:4000` in your browser
